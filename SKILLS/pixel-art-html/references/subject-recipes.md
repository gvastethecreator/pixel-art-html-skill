# Subject routing

This compatibility index replaces the old catch-all recipe corpus. Load one branch, not all four:

- [characters-creatures.md](subjects/characters-creatures.md): characters, portraits, monsters, poses, and frame masters.
- [props-ui.md](subjects/props-ui.md): icons, pickups, food, equipment, UI tokens, and gameplay-readable objects.
- [vehicles-architecture.md](subjects/vehicles-architecture.md): ships, aircraft, mecha, buildings, interiors, and structural scale.
- [environments-tiles.md](subjects/environments-tiles.md): terrain, foliage, water, rocks, backgrounds, materials, tiles, and seams.

Shared construction belongs in [craft-workflow.md](craft-workflow.md). Do not load an unrelated subject branch “for inspiration”; it adds constraints that do not apply.
