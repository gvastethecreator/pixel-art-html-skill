# Props, icons, and UI

## Direction choices

- Define the affordance first: health, key, currency, hazard, quest item, weapon, food, or state.
- Lead with one iconic silhouette and one identity cutout, protrusion, or asymmetry.
- For a family, fix projection, light, baseline, padding, outline strength, and palette roles; keep item silhouettes distinct.
- Reserve a glow, shine, or saturated accent for the focal cue — it cannot replace object recognition.

## Build

1. Block the object as two or three masses inside a consistent frame.
2. Test among neighbors or on the intended HUD/game background at native size.
3. Plane-shaped highlights: narrow hard edges for metal or glass, broad soft clusters for cloth or food, chipped irregular breaks for stone or wood.
4. Keep cast shadows short and consistent. Separate them if the object must work on several backgrounds.
5. In a pack, shuffle labels and confirm every item plus the family read.

## Reject

- a plain rectangle, circle, or bottle outline with detail pasted inside
- four items distinguishable only by hue
- shine clusters that imply the wrong material
- equal contrast on every object feature
- padding or baseline drift across a set
- food produced as a noisy photographic thumbnail
- UI tokens whose appearance contradicts behavior or danger
