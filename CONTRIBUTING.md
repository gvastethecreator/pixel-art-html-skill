# Contributing

Thanks for improving Pixel Art HTML. Keep public documentation in American English.

1. Keep generated drafts and scratch evidence out of the repository.
2. Preserve exact-grid metadata, provenance, and reviewer boundaries.
3. Run `pnpm run check:core` for dependency-free changes.
4. Install Pillow 12.3.0 and run `pnpm run check:full` when image conversion, packing, or reference media tools change.
5. Include a focused fixture or regression only when behavior changes.

Do not promote an artifact to representative or production-candidate without the required independent review.

Keep reference corpora, full source text, local indexes, and sampled boards private. The technique catalog contains original synthesis and source links. Changes to its artistic guidance need source evidence or an observed workflow result; test counts cannot establish art quality.
